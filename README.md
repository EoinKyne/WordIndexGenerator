# Word Index Generator

An application to build and index of words with their definitions

<b>main</b><br>
model contains the class the describes the word<br>
service contains the logic to build the index<br>
utils contain utility classes for the application<br>

<b>test</b><br>
integration contains the integration test<br>
service contains the tests on service classes<br>
utils contains the tests for util classes<br>

<b>.github</b><br>
workflows contains the workflows for the application (e.g executes the tests on push to main branch)
